# Ethio-Digital Excellence

## Student Management System

Ethio-Digital Excellence is a web-based student registration and management system designed to help manage student information digitally.

## Features

- Student registration
- View student information
- Edit student information
- Delete individual students
- Delete all students
- Student statistics
- Course statistics
- Admin login
- Admin logout
- Mobile-friendly interface
- Local data storage

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Admin Features

The admin dashboard allows authorized administrators to:

1. View registered students
2. Edit student information
3. Delete students
4. View statistics
5. Manage student records

## Project Structure

- `index.html` - Main website page
- `login.html` - Admin login page
- `admin.html` - Admin dashboard

## Data Storage

Student information is currently stored in the browser using LocalStorage.

## Purpose

The purpose of this project is to provide a simple and accessible digital platform for student registration and management.
